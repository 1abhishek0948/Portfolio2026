Software Engineering Skills

The languages, frameworks and tools I use to build, connect and deploy web applications — sharpened on real projects rather than tutorials.

Languages

Python, JavaScript, C

Python is my primary language for backend development and automation, JavaScript for interactive interfaces, and C for understanding what happens at a lower level.

Backend

Django, Flask, Node.js & Express

Django for full-featured applications with ORM, authentication and admin, Flask for small services and tools, Node.js and Express when JavaScript end-to-end makes sense.

Frontend

React.js, HTML, CSS, Tailwind, Bootstrap

Component-driven interfaces in React, semantic and accessible HTML, responsive CSS layouts, and utility-first or component frameworks for faster UI work.

Databases

PostgreSQL, MySQL, MongoDB

Relational modelling and SQL for structured data, PostgreSQL as my default choice for production apps, and MongoDB for document-shaped use cases.

APIs & integration

REST APIs, JWT, external services

Designing and consuming REST APIs, JWT-based authentication, and integrating payment, email, AI and third-party services securely.

Tools & deployment

Git, GitHub, Docker, Render

Version control and collaboration through Git and GitHub, containerised environments with Docker, and deployment and hosting on platforms like Render.

AI & vision

Machine learning fundamentals, OpenCV

Applied machine learning basics and OpenCV-based computer vision, used in assistive projects and AI-powered features such as chatbots and LLM integrations.

SEO & quality

Technical SEO, accessibility, performance

Semantic HTML, metadata and structured data, Core Web Vitals, and accessibility practices — the technical foundation that makes websites findable and fast.

Skills in practice

Skills only matter in the context of shipped software. LAHAN Hub is a full Django/PostgreSQL ecosystem, Lafzloom combines Django REST APIs with a Tailwind frontend, and the Blind Assistance System applies Python and OpenCV to a real accessibility problem. If you're looking for help with a project, these skills map directly to my development services.

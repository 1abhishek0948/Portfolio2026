Blind Assistance System

The Blind Assistance System is an assistive technology project designed to help visually impaired users understand aspects of their surroundings through computer vision, object detection, distance sensing and voice feedback.

Technical approach

Abhishek built the project with Python, OpenCV and Raspberry Pi. The system combines camera-based processing and distance detection with spoken alerts. It is a practical computer-vision experiment, not a claim of complete independent navigation.

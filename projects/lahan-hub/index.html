LAHAN Hub

LAHAN Hub is Abhishek Thakur's largest full-stack project: a digital city ecosystem bringing local services, businesses, community features, information and everyday utilities into one platform.

Implementation

The project is built with Python and Django, uses PostgreSQL for its data layer and Docker for its development and deployment environment. Its scope includes 21 interconnected applications, including marketplace, jobs, community, weather and notifications.

Lafzloom

Lafzloom is a full-stack platform for discovering, writing, translating, saving and sharing poetry. It combines a Django backend and PostgreSQL data layer with a Tailwind interface.

Features and implementation

The project includes search, moderation, multilingual support, REST APIs and JWT authentication. It gave Abhishek practical experience modelling content, designing API flows and building a focused product experience.
